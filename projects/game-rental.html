Game Rental Management System

WinForms application with SQL Server backend for efficient game rentals

Tech Stack: C# SQL Server WinForms
Categories: Database Systems Desktop Application Inventory Management

Database Design

7-table normalized schema with proper relationships:

User Tables

  • Account: Base credentials (ACC_ID PK)
  • Customer: Age, Phone (ACC_ID FK)
  • Admin: Vendor management (ACC_ID FK)

Game Tables

  • Game: Title, Vendor (Game_ID PK)
  • Browse: Customer viewing history

Transaction Tables

  • Rent: S_Date, E_Date (rent_id PK)
  • Return: Track completed rentals
