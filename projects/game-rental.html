Game Rental Management System

WinForms application with SQL Server backend for efficient game rentals

Tech Stack: C# SQL Server WinForms
Categories: Database Systems Desktop Application Inventory Management

Project Value Proposition

providing vendors with real-time analytics on rental performance.

Key Features

Role-Based Access

  • Admin: Add/update games
  • Clients: Browse & rent games
  • Vendors: View game performance

Game Management

  • Add new game entries
  • Update existing game details
  • Filter by year/vendor/category

Rental Operations

  • Check-out/return system
  • Rental history tracking
  • Late return detection

Database Design

Normalized schema supporting complex rental analytics with 6 core tables:

  • Users: Admin/Clients/Vendors
  • Games: Title, Year, Category
  • Rentals: DateOut, DateReturned
  • Vendors: Developer relationships

Analytical Queries

Top Performing Game

SELECT TOP 1 g.Title, COUNT(r.RentalID) AS RentCount
FROM Games g JOIN Rentals r ON g.GameID = r.GameID
GROUP BY g.Title ORDER BY RentCount DESC;

Inactive Vendors

SELECT v.VendorName FROM Vendors v
WHERE NOT EXISTS (
  SELECT 1 FROM Games g JOIN Rentals r ON g.GameID = r.GameID
  WHERE g.VendorID = v.VendorID
  AND r.DateOut >= DATEADD(month, -1, GETDATE())
);
