Game Rental Management System

WinForms application with SQL Server backend for efficient game rentals

Tech Stack: C# SQL Server WinForms
Categories: Database Systems Desktop Application Inventory Management

How It Works

The system has three main components:

  1. Users: Admins manage games, customers rent them
  2. Games: Catalog with titles, categories, and vendors
  3. Transactions: Tracking rentals and returns

Key Features

For Customers

  • Browse available games
  • Rent with due dates
  • Return tracking

Game Management

  • Add new game entries
  • Update existing game details
  • Filter by year/vendor/category

Rental Operations

  • Check-out/return system
  • Rental history tracking
  • Late return detection
