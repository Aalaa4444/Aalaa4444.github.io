Game Rental System

A complete solution for managing video game rentals with C# (WinForms application) and SQL Server

Tech Stack: C# SQL Server WinForms ADO.NET
Categories: Database Systems Desktop Application Inventory Management

How It Works

The system has three main components:

  1. Users: Admins manage games, customers rent them
  2. Games: Catalog with titles, categories, and vendors
  3. Transactions: Tracking rentals and returns

Key Features

For Customers

  • Browse available games
  • Rent with due dates
  • Return tracking

For Admins

  • Add/update game details
  • View rental analytics
  • Manage vendors

Database Highlights

The system uses these main tables:

CREATE TABLE Game ( Game_ID INT IDENTITY(1,1) PRIMARY KEY, Title VARCHAR(55) NOT NULL, Year INT, Category VARCHAR(55), vendor VARCHAR(55) NOT NULL );

Relationships ensure data stays accurate:

  • Customers must have valid accounts
  • Every rental links to a specific game
  • Returns match existing rentals

Technical Details

C# WinForms for the desktop interface

SQL Server for data storage

ADO.NET for database connections
