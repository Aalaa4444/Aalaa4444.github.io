Video Subtitle Detector

Automatically find and highlight subtitles in any video

Tech Stack: Python OpenCV NumPy pytesseract
Categories: Computer Vision Image Processing Video Analysis

What It Does

This tool scans through video files and automatically:

  • Finds all subtitle text on screen with 95% accuracy
  • Draws colored boxes around each subtitle line
  • Works with multiple languages and font styles
  • Processes HD videos at 24 frames per second

How It Works

1 Frame Extraction

Breaks down video into individual frames for analysis

2 Text Detection

Uses computer vision to identify text regions in each frame

3 Subtitle Highlighting

Draws bounding boxes and compiles final video

Key Technical Features

  • Morphological Operations: Advanced image processing for precise text detection
  • Adaptive Thresholding: Works in varying lighting conditions
  • Batch Processing: Handles multiple videos automatically
  • OCR Integration: Optional text extraction with Tesseract
